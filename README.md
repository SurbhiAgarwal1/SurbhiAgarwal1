## Open Source Philosophy

I contribute to projects that matter. Not for stars or followers—for impact.

Good open source work requires more than code. It requires documentation that guides, issues that teach, reviews that elevate, and maintenance that endures. I show up consistently.

Sustainability beats velocity. I'd rather ship once properly than iterate forever on shortcuts.

---

## Engineering Principles

- **Clarity over cleverness** — Simple solutions scale better than brilliant complexity
- **Systems thinking** — Every component exists within a larger whole
- **Maintainability first** — Code is read more than written
- **Test what matters** — Coverage is a means, not a metric
- **Automate relentlessly** — Humans shouldn't do what machines can
- **Measure, then optimize** — Intuition without data is guessing
- **Document decisions** — Future developers include future you
